# Poem Web

A simple web page displaying a personal poem using HTML, CSS, and JavaScript.  
The project includes a styled layout, a short script, and a minimal design focused on readability and atmosphere.

## Files included

- **index.html** – Main structure of the page  
- **style.css** – Visual styling for the poem and layout  
- **script.js** – Small JavaScript function for console output  

## Purpose

This project is a small creative exercise combining basic web technologies with personal expression.  
It serves as practice for structuring a webpage, applying custom styles, and organizing a simple project.

## How to view

Open `index.html` in any browser to see the poem rendered with its styles.
